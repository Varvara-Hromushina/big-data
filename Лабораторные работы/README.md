## Описание лабораторных работ

### [Лабораторная работа №1: Введение в язык R](./Лаб.1%20Введение%20в%20язык%20R.pdf)
*   **Цель:** Освоить базовые конструкции языка R, типы данных, структуры (векторы, матрицы, списки, фреймы данных), управляющие конструкции и написание простых функций.
*   **Ключевые темы:**
    *   Основы синтаксиса и работа в консоли.
    *   Атомарные и общие типы данных (векторы, матрицы, массивы, списки, фреймы данных, факторы).
    *   Создание, индексация и модификация объектов.
    *   Математические и статистические функции.
    *   Управляющие конструкции (`if`, `for`, `while`).
    *   Написание пользовательских функций.
    *   Работа с пакетами расширений.
*   **Примеры заданий:** Создание векторов из последовательностей, индексация, манипуляции с фреймами данных, решение задач с использованием базовых функций.

### [Лабораторная работа №2: Подготовка, дескриптивный анализ и визуализация данных](./Лаб_2_1_Способы_подготовки_и_отображения_данных_в_R.pdf) & [Часть 2.2](./Лаб_2_2_Дескриптивный_анализ_данных_в_R.pdf)
*   **Цель:** Научиться подготавливать данные для анализа, импортировать их из различных источников, проводить первичный (дескриптивный) анализ и визуализировать основные статистические характеристики.
*   **Ключевые темы:**
    *   Импорт данных из CSV, Excel и текстовых файлов.
    *   Обработка пропущенных значений (NA).
    *   Преобразование типов данных (факторы, даты).
    *   Дескриптивная статистика (`summary`, `mean`, `sd`, `quantile`, `IQR`).
    *   Векторизованные вычисления и функции `apply` семейства.
    *   Визуализация: гистограммы (`hist`), ящики с усами (`boxplot`).
    *   Слияние (`merge`), объединение (`rbind`, `cbind`) и фильтрация (`subset`) наборов данных.
*   **Примеры заданий:** Проведение мини-опроса, импорт данных, расчет основных статистик, построение графиков распределения для разных групп.

### [Лабораторная работа №3: Продвинутая работа с графиками и диаграммами](./Лаб_3_Работа_с_графиками_и_диаграммами_в_R.pdf)
*   **Цель:** Освоить продвинутые приемы настройки графиков, добавления аннотаций, легенд и объединения нескольких диаграмм в одном окне для создания информативных и публикабельных визуализаций.
*   **Ключевые темы:**
    *   Управление графическими параметрами (`par`, `mfrow`, `layout`).
    *   Настройка типов линий (`lty`), символов (`pch`), цветов (`col`).
    *   Добавление заголовков, подписей осей и текстовых аннотаций (`title`, `mtext`, `text`).
    *   Создание и настройка осей (`axis`).
    *   Добавление условных обозначений (`legend`).
    *   Настройка шрифтов и размеров.
*   **Примеры заданий:** Анализ данных PISA (оценки школьников по математике, чтению и естественным наукам): построение графиков динамики, сравнение стран, визуализация по гендерному признаку.

### [Лабораторная работа №4: Извлечение данных с WEB-страниц (Web Scraping)](./Лаб_4_Извлечение_данных_с_WEB-страниц.pdf)
*   **Цель:** Познакомиться с технологией веб-скрейпинга и научиться извлекать и структурировать данные с веб-сайтов с использованием пакета `rvest` в R.
*   **Ключевые темы:**
    *   Парсинг HTML-страниц (`read_html`).
    *   Использование CSS-селекторов и XPath для извлечения элементов (`html_nodes`).
    *   Извлечение текста (`html_text`), атрибутов (`html_attr`), таблиц (`html_table`).
    *   Навигация по сайтам с использованием сессий (`html_session`).
    *   Работа с формами (`html_form`, `set_values`, `submit_form`).
*   **Примеры заданий:** Сбор данных об уровне жизни стран с сайта Numbeo, извлечение информации о музеях, парсинг списка олимпийских медалей.

### [Лабораторная работа №5.1: Задачи классификации и кластеризации](./Лаб_5_1_Задачи_классификации_и_кластеризации.pdf)
*   **Цель:** Изучить задачи кластеризации (обучение без учителя) и многомерной классификации (обучение с учителем) на языке R.
*   **Ключевые темы:**
    *   Стандартизация данных (`scale`).
    *   Иерархическая кластеризация (`hclust`) и построение дендрограмм.
    *   Определение оптимального числа кластеров: метод локтя, метод силуэта, статистика разрыва.
    *   Кластеризация методом K-средних (`kmeans`).
    *   Визуализация кластеров (`factoextra`).
    *   Диаграммы рассеяния (scatterplot), матрицы диаграмм рассеяния (`pairs`).
    *   Трехмерная визуализация (`scatterplot3d`).
*   **Примеры заданий:** Кластеризация наборов данных для выявления скрытых групп (например, экономика городов, покупатели магазина).

### [Лабораторная работа №5.2: Байесовская классификация и деревья принятия решений](./lab5_2_R__Bayes_DTree.docx)
*   **Цель:** Научиться применять алгоритмы классификации с учителем: наивный байесовский классификатор, деревья решений и случайный лес для прогнозирования принадлежности объектов к известным классам.
*   **Ключевые темы:**
    *   Теорема Байеса и наивный байесовский подход (`NaiveBayes` из `klaR` или `naiveBayes` из `e1071`).
    *   Построение и визуализация деревьев решений (`ctree` из `party`).
    *   Оценка точности модели с помощью матрицы ошибок (`confusion matrix`).
    *   Алгоритм "Случайный лес" (`randomForest`).
    *   Применение обученных моделей к тестовой выборке (`predict`).
*   **Примеры заданий:** Классификация цветов ириса, классификация на основе результатов кластерного анализа из ЛР 5.1.

### [Лабораторная работа №6: Проверка статистических гипотез](./lab6_R_Hypot.doc)
*   **Цель:** Изучить основные статистические тесты, используемые в R, принципы их работы и научиться интерпретировать результаты для принятия решений о свойствах выборок.
*   **Ключевые темы:**
    *   Понятие нулевой и альтернативной гипотезы, ошибки I и II рода, p-value и уровень значимости.
    *   Проверка нормальности распределения (тест Шапиро-Уилка (`shapiro.test`), квантильные графики (`qqnorm`)).
    *   Тест на равенство дисперсий (тест Бартлетта (`bartlett.test`)).
    *   Одновыборочный t-тест (проверка гипотезы о среднем).
    *   Двухвыборочный t-тест Стьюдента (`t.test`) и его непараметрический аналог (тест Уилкоксона (`wilcox.test`)).
*   **Примеры заданий:** Анализ данных о спортсменах (вес, вид спорта), проверка гипотез о различиях между группами.

### [Лабораторная работа №7: Корреляционный и регрессионный анализ данных](./lab7_R_Regr_Corr.doc)
*   **Цель:** Овладеть методами корреляционного анализа для оценки связей между переменными и регрессионного анализа для построения прогностических моделей.
*   **Ключевые темы:**
    *   Коэффициенты корреляции Пирсона, Спирмена и Кендалла (`cor`, `cor.test`).
    *   Визуализация корреляционной матрицы (`corrgram`, `ellipse`).
    *   Построение простых и множественных линейных регрессионных моделей (`lm`).
    *   Полиномиальная регрессия.
    *   Интерпретация результатов регрессии (`summary`, коэффициенты, R-squared, p-value).
    *   Использование модели для прогнозирования (`predict`).
*   **Примеры заданий:** Анализ макроэкономических данных (ВВП, население, образование) с целью выявления взаимосвязей и построения прогнозов.
